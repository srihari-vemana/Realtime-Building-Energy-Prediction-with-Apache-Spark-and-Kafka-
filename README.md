# Realtime-Building-Energy-Prediction-with-Apache-Spark-and-Kafka-
PySpark code for EDA of Building energy Dataset to build a Energy usage prediction model which is then used to perform real-time predictions on streamed data. Visualised using Kafka consumers and matplotlib.<br>

For detailed context, please refer to the "Context.pdf" file within each sub-folder.<br>
This project was created as a part of my course work at Monash University's "FIT5202 Data processing for Big Data" unit.
